# راهنمای استفاده

## نصب
۱. روی فایل `DentalPatients-Setup-<نسخه>.exe` دو بار کلیک کنید.
۲. روی **Install** کلیک کنید.
۳. برنامه از منوی Start یا میانبر دسکتاپ اجرا می‌شود.

در نخستین اجرا، فایل CSV اولیه‌ی بیماران به‌طور خودکار وارد پایگاه داده
می‌شود. پس از آن، تمام اطلاعات روی همین رایانه نگه‌داری می‌شود
(`%APPDATA%\DentalPatients\patients.db`).

## کار با برنامه

| کار | چگونه |
|-----|-------|
| جستجو | تایپ در نوار جستجو در بالای پنجره. نتایج با تاخیر بسیار کم به‌روزرسانی می‌شود. |
| افزودن بیمار جدید | دکمه «➕ افزودن بیمار» یا کلید میانبر **Ctrl + N** |
| ویرایش بیمار | دو بار کلیک روی ردیف، یا انتخاب و کلید **Enter** |
| حذف بیمار | انتخاب ردیف و کلید **Delete** (همراه با تاییدیه) |
| فوکوس روی نوار جستجو | کلید **Ctrl + F** |

### نکته در مورد جستجو
- جستجو روی نام، شماره پرونده، تلفن و یادداشت کار می‌کند.
- شما می‌توانید با ارقام فارسی یا انگلیسی جستجو کنید — هر دو معادل هستند.
- تفاوت «ی» عربی و فارسی، یا «ک» و «ك» در جستجو نادیده گرفته می‌شود.

## پشتیبان‌گیری
- **خودکار**: در نخستین اجرای هر روز، یک پشتیبان در مسیر زیر ساخته می‌شود:
  `%APPDATA%\DentalPatients\backups\`. ۳۰ پشتیبان آخر نگه داشته می‌شود.
- **دستی**: از منوی **ابزارها → ایجاد پشتیبان**.
- **بازگردانی**: اگر برنامه در زمان شروع متوجه آسیب‌دیدگی پایگاه داده شود،
  گزینه بازگردانی از آخرین پشتیبان به صورت خودکار پیشنهاد می‌شود.

## سطل بازیافت
بیماران حذف‌شده به سطل بازیافت منتقل می‌شوند و قابل بازگردانی هستند:
**ابزارها → سطل بازیافت**.

## خروجی CSV
از منوی **پرونده → ذخیره خروجی CSV** می‌توانید یک فایل CSV از تمام بیماران
بسازید. فایل خروجی با کدبندی UTF-8 (با BOM) ذخیره می‌شود تا در Excel فارسی
به‌درستی نمایش داده شود.

## به‌روزرسانی برنامه
هرگاه نسخه جدیدی از برنامه به شما داده شد:
۱. روی فایل `DentalPatients-Setup-<نسخه‌ی جدید>.exe` دو بار کلیک کنید.
۲. روی **Install** کلیک کنید.
۳. برنامه به‌طور خودکار جای‌گزین نسخه‌ی قبلی می‌شود — **هیچ یک از اطلاعات
بیماران از دست نمی‌رود**.

## مشکل‌یابی

| مشکل | راه‌حل |
|------|--------|
| برنامه باز نمی‌شود | با کلیک راست → Run as administrator امتحان کنید. |
| هشدار «پایگاه داده آسیب دیده» | روی «بازگردانی» کلیک کنید تا پشتیبان قبلی برگردد. |
| می‌خواهم پوشه اطلاعات را ببینم | از منوی **ابزارها → نمایش پوشه اطلاعات**. |
